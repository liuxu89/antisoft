# Antisoft

Antisoft 技术博客，基于 [VitePress](https://vitepress.dev) 构建，通过 GitHub Actions 自动部署到 GitHub Pages。

## 访问地址

🔗 **https://liuxu89.github.io/antisoft/**

## 本地开发

```bash
npm install
npm run docs:dev
```

## 构建与部署

推送到 `main` 分支后，GitHub Actions 会自动构建并发布：

```bash
npm run docs:build
```

## 栏目

- **Python**：不定期更新
- **文章**：开发经验与思考
- **指南**：工具链操作步骤
